## 📖 專題簡介 (Project Overview)
大眾衣櫃中普遍存在「丟掉可惜、穿出門又不知如何搭配」的閒置衣物與老舊配飾。
《RE:CLOTHES 拾衣研究所》是一個為解決此痛點而設計的互動提案平台，運用商業設計美感與 AI 靈感生成，為每件衣物與配件量身打造「痛點分析」、「風格穿搭公式」、「結構改造構想」、「AI 生圖 Prompt 紀錄」以及「**AI 概念視覺模擬圖 (Before/After 對照)**」。

本網站支援**完整 7 國語言即時切換（繁體中文 🇹🇼 / English 🇺🇸 / 日本語 🇯🇵 / 한국어 🇰🇷 / Español 🇪🇸 / Deutsch 🇩🇪 / العربية 🇸🇦，包含阿拉伯語 RTL 鏡向閱讀排版）**，全面接軌國際永續時尚美學與課程國際化講義標準。

## ✨ 核心特色與符合評分指南規範

1. **七國語言即時切換 (Multilingual i18n & RTL Support)**：
   - 支援 繁體中文、English、日本語、한국어（韓文）、Español（西班牙文）、Deutsch（德文）與 العربية（阿拉伯語，含 RTL 排版）。
   - 包含介面、標籤、按鈕、痛點說明、9 套單品與配飾改造資料庫與 AI 試用區的多語系支援。
   - 切換語言即時生效，並透過 `localStorage` 永久保存使用者的語言喜好。

2. **首頁精選案例牆（含閒置配飾改造與 AI 模擬圖）**：
   - 每張卡片均呈現清楚的「**原單品 (Before) ➔ 改造／搭配方向 (After)**」對比。
   - 涵蓋**衣物與閒置配飾**（襯衫、丹寧、T恤、西裝外套、洋裝、針織、絲巾、老皮帶、磨損帆布鞋等）。
   - 每張卡片皆展示「**✨ AI 概念視覺模擬圖**」，一目了然看見改造後的設計質感。
   - 支援單品與配飾類別篩選（包含「🎀 閒置配飾」專屬分類）、難易度過濾與即時關鍵字搜尋。

3. **案例詳情頁 (Modal 彈窗)**：
   點進任一單品卡片，完整呈現 5 大核心板塊：
   - **零、 AI 概念視覺模擬對照**：高清呈現「改造前原狀 (Before)」與「AI 概念模擬改造後 (After)」，標註質感關鍵字。
   - **一、 單品痛點分析**：深入剖析版型困境、材質特性與身材比例問題。
   - **二、 穿搭搭配建議**：提供 2~3 種不破壞衣物的日常穿搭層次公式。
   - **三、 結構改造構想**：分解工藝步驟 1-2-3、工具清單與設計師防失誤小撇步。
   - **四、 當時使用的 Prompt 紀錄**：保留當時生成該視覺提案的 Midjourney / AI Prompt，並提供「**一鍵複製 Prompt**」功能。

4. **自己的試用區 (AI 提案生成器)**：
   - 使用者可輸入自身衣物或配件的名稱、材質、痛點、期望風格與偏好模式。
   - 提供「快速帶入範例」按鈕（包含襯衫、洋裝與「老花絲巾配飾」示範）供現場評審或同學一秒試用。
   - 生成提案後即時附帶 AI 模擬概念圖預覽，並提供「**📥 將此提案儲存至上方案例牆**」按鈕，立即發布為新卡片！

5. **資料管理加分功能 (CRUD 滿分規劃)**：
   - **C (Create)**：可點擊「新增自訂案例」手動發布，或自試用區直接加入。
   - **R (Read)**：多維度檢視案例詳情、篩選與搜尋。
   - **U (Update)**：點擊任一卡片右上角編輯按鈕，彈窗修改即時生效更新。
   - **D (Delete)**：支援刪除案例，並具備確認對話框防誤觸。
   - **資料保存**：所有變更即時同步至瀏覽器 `localStorage`，重新整理不遺失。
   - **貼心備份**：提供「恢復預設範例」、「匯出 JSON」與「匯入備份」功能。
